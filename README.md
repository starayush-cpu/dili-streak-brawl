# Dili Streak Brawl

A Metal Slug-style run-and-gun browser game starring **Dili**, the mascot of the
Dlicom community. Fight through 5 stages, rescue POWs, grab weapon pickups and
take down 5 different bosses — then keep going in Endless Mode.

## Play

Just open `index.html` in any modern browser (phone or PC). No build step, no
server, no external files — everything is in that one file.

## Controls

- **PC:** Arrow keys / WASD to move, `Z` shoot, `X` / `K` jump, `C` grenade,
  `P` pause, `F` fullscreen, `M` mute. Gamepad supported.
- **Mobile:** on-screen joystick and buttons (move, shoot, jump, crouch,
  grenade) on a dedicated control deck below the play area — they never cover
  the game.

## Features

- 5 stages (Jungle Outpost, Desert Foundry, Neon Harbor, Frozen Crypto Mine,
  The Sky Vault) with 5 different bosses, plus Endless Mode
- Movie-style presentation: opening film card, CHAPTER titles, talking
  dialogue scenes and animated cutscenes after each stage — all in English
- Funny crypto story: recover the community's stolen BTC, ETH and $DLI vault
- POW rescues join Dili as fighting allies; BTC/ETH/$DLI coin pickups
- New enemies (Brute, Bomber, Dasher, Golden Goon), combos, Shield / Coin
  Magnet power-ups, mid-stage checkpoints, heart pickups
- Real Dili character and Dlicom logo, all English UI
- Session-only leaderboard (scores stay on the device)

## Deploy on Vercel

Import this repo in Vercel, set Framework Preset to **Other**, leave the build
command empty, and deploy. `index.html` sits at the repo root.
